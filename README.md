# student-performance-ml
Predict student exam scores based on study habits using linear regression and other models.

#Project Goals
- Explore correlations between daily habits and exam performance
- Build regression models (Linear, Random Forest)
- Compare model performance using R² and RMSE
- Identify the most important features influencing exam results

# Features Used
- Study hours per day
- Social media usage
- Netflix hours
- Sleep hours
- Attendance percentage
- Mental health rating
- Exercise frequency

# Models Trained
- Linear Regression
- Ridge Regression
- Random Forest Regressor

# Evaluation Metrics
- R² Score
- RMSE (Root Mean Squared Error)
- Cross-validation scores

# Key Insights
- Study hours had the highest impact on performance
- Mental health was a surprisingly strong predictor
- Random Forest outperformed linear models
